# Canva アニメ復元ツール

CanvaからダウンロードしたPPTXは、アニメーションと画面切り替えが消えています。
このツールは、そのPPTXに **PowerPoint本物のアニメーション** を付け直すWebアプリです。

- サーバー不要。ファイルはブラウザ内だけで処理され、外部へ送信されません。
- インストール不要。`index.html` を開くだけで動きます(オフラインでも可)。

## 使い方

1. Canvaで「共有 → ダウンロード → ファイルの種類: PPTX」を選んで保存します。
2. `index.html` を開き、PPTXをドラッグ&ドロップします。
3. 要素を選んで効果を設定します。「一括設定」を使うと、読み順(上→下、左→右)に自動で割り当てられます。
4. 「▶ プレビュー再生」で動きを確認します。
5. 「PPTXをダウンロード」で保存し、PowerPointで開きます。
6. Googleスライドで使うときは、できたPPTXをGoogleドライブにアップロードして「Googleスライドで開く」を選びます。

## 設定できるもの

| 種類 | 内容 |
|---|---|
| 開始の効果 | 表示 / フェードイン / スライドイン(4方向) / ワイプ(4方向) / ズームイン |
| 終了の効果 | 消える / フェードアウト |
| タイミング | クリックで / 前と同時 / 前の後に、時間、遅延 |
| 画面切り替え | なし / フェード / プッシュ / ワイプ / ズーム(スライドごと、または全スライド) |

1つの要素に複数のアニメーションを付けられます(例: フェードインしてから、フェードアウト)。

## できないこと・注意点

- **Canvaで付けたアニメーションを自動で読み取ることはできません。** CanvaがPPTXにも公式APIにもその情報を出さないためです。再現したい動きは、このツールで付け直します。
- グループ化された要素は、グループ全体が1つの対象になります。
- プレビューは目安です。位置・文字サイズ・画像の切り抜きは近似で描画します。
- Googleスライドは対応するアニメーションの種類が限られるため、一部の効果は別の効果に置き換わることがあります。
- 元のPPTXにすでにアニメーションがある場合、そのスライドは **設定を変更したときだけ** 置き換えます。変更していないスライドはそのままです。

## ほかのPCで使う

- **そのまま配る:** `canva-anim` フォルダごとコピーして、`index.html` を開きます。
- **URLで共有する:** `canva-anim` フォルダを静的ホスティング(GitHub Pages、Netlify など)に置きます。ビルド作業は要りません。

## 構成

```
index.html      画面
style.css       見た目
app.js          PPTXの読み込み・プレビュー・書き出し
pptx-anim.js    アニメーションXML(p:timing / p:transition)の生成ロジック
vendor/         JSZip (MIT)
tests/          動作確認用スクリプト
```

## 動作確認

```sh
pip install python-pptx
python3 tests/make_sample.py sample.pptx some.png        # サンプルPPTXを作る
node tests/e2e.mjs sample.pptx out.pptx                  # ブラウザ(Playwright)で操作して書き出す
node tests/all_effects.mjs sample.pptx all.pptx          # 全効果・全方向を埋め込む
```

書き出したPPTXは、LibreOffice Impressで開いて意図どおりのアニメーションとして解釈されることを確認しています
(全効果・全方向・クリック/同時/後・画面切り替え)。ただし実際のPowerPointでの表示は未確認なので、最初は手元で一度スライドショーを再生して確かめてください。
